## Adaptation boundaries

The fork's complete Next.js monorepo remains available as the source reference. The local Astro implementation does not need its database, CMS, accounts, paid courses, Stripe, Kit email subscriptions, Inngest workflows or video services. These services would not improve the static eleven-skill catalogue.

Use our local `src/data/skills.ts` for the three primary groups and quieter optional practices. Use `src/data/install.ts` for verified official skills CLI commands and Claude Code plugin registration/install commands. `.claude-plugin/` exposes the canonical root skills; the plugin channel remains local until publication. Show our verified skill count, package requirements and actual links. Do not transfer AI Hero's email-course offer, company testimonials, GitHub star count or install badges as Field Guide/MrCoder metrics.

The existing 66 published package/download/asset files remain byte-for-byte intact. The command generator is checked against an independent source/branch, alias/dependency and plugin-metadata contract. It does not replace or refresh the preservation baseline. The former curl/Bash endpoint is superseded and removed.
